# Algo

Personal archive of LeetCode solutions and data structure implementations, written in six languages. Features per-difficulty progress bars counted from solution files, upcoming meetup.com/algoatx events scraped at build, solution pages with difficulty badges and copyable Shiki-highlighted code, slash-shortcut search over a prerendered index, custom 404 and 500 pages, and a LeetCode sync script that scaffolds missing problems. Built with Astro, TypeScript, Tailwind CSS, and GSAP. Deployed on Netlify.
